# PR description template

Use the repository's own template (`.github/pull_request_template.md`) if it exists. Otherwise, use this one:

```markdown
## What
<one or two sentences: what this change does>

## Why
<the problem / requirement>. Closes #<issue>   <!-- or: Refs #<issue> -->

## How
- <key change 1>
- <key change 2>

## Acceptance criteria
- [x] <criterion> - <how it's satisfied>

## Testing
- Ran: `<command>` → <result>
- Manual: <steps checked>
- Not tested: <what and why>

## Risk & review notes
- <anything risky, surprising, or worth a second look>
- Related/overlapping PRs: <#n or none>
- Needs tech lead review: <yes/no - why>

## Screenshots
<before / after for UI changes>
```

Keep it factual. No AI attribution lines.
